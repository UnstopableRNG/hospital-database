# Hospital Database

A relational database project developed as part of my studies in Digital Forensics and Cyber Security at TU Dublin.

## Overview

This project focuses on the design and implementation of a hospital database using SQL.

The project includes database design diagrams and SQL scripts covering the creation and management of the database and its data.

## Database Design

The database design was developed through three stages:

- Conceptual database design
- Logical database design
- Physical database design

The corresponding ER diagrams are included in this repository.

## SQL

The project includes SQL scripts demonstrating database operations and queries, including:

- Database and table creation
- Data insertion
- Data updates
- Data deletion
- SELECT queries
- Filtering and sorting
- Joins
- Aggregate functions
- Database views
